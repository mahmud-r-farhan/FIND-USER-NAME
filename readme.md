# Find User Name | Find Social Profiles |

## Overview

**Find User Name | Find Social Profiles** is your go-to digital investigation tool for tracking down social media profiles across multiple platforms. Designed to simplify the process of finding users online, this application is perfect for researchers, recruiters, digital marketers, and anyone needing to identify or verify social media profiles.

## Features

-   **Social Media Search**: Locate profiles on a wide range of social media platforms.
    
-   **Username Lookup**: Search for specific usernames across platforms.
    
-   **Profile Search Tool**: Comprehensive search capabilities to find detailed user profiles.
    
-   **Availability Checker**: Check the availability of usernames on various social media sites.
    
-   **Efficient and Fast**: Quickly fetch results to save time.
    
-   **User-Friendly Interface**: Designed for simplicity and ease of use.
    

## Use Cases

-   **Recruiters and HR Professionals**: Verify candidate profiles.
    
-   **Digital Marketers**: Identify and connect with influencers or competitors.
    
-   **Private Investigators**: Conduct online investigations.
    
-   **Individuals**: Find friends or reconnect with lost contacts.
    

## How It Works

1.  **Enter the Username**: Input the username you wish to look up.
    
2.  **Select Platforms**: Choose the social media platforms you want to search on.
    
3.  **Search**: Hit the search button and let the application do the work.
    
4.  **View Results**: Explore the list of matching profiles with detailed information.
    

## Technology Stack

-   **Frontend**: React.js, Tailwind CSS and Sonner
  
    

## Getting Started

### Prerequisites

-   Node.js installed on your machine
    

### Installation

1.  Clone the repository:
    
    ```
    git clone https://github.com/mahmud-r-farhan/FIND-USER-NAME
    ```
    
2.  Navigate to the project directory:
    
    ```
    cd find-user-name
    ```
    
3.  Install dependencies:
    
    ```
    npm install
    ```
    

### Running the Project

  
1.  Start the frontend development server:
    
    ```
    npm start
    ```
    
3.  Open your browser and navigate to `http://localhost:3000`.
